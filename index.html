            01 / Sobre mim
            
Comecei no suporte. Hoje construo sistemas.

          

          

            

              Sou Marcos Gabriel, desenvolvedor Full Stack e
              Analista de T.I. Comecei na área com suporte técnico e automações.
              Fui migrando para o desenvolvimento porque gostava mais de criar
              sistemas do que de manter os que já estavam prontos.
            

            

              Hoje trabalho principalmente com sistemas web
              usando Flask e Django, aplicações desktop com
              PyQt5 e bancos de dados como SQL Server,
              PostgreSQL e MongoDB. Também faço automação e
              integração entre sistemas para cortar trabalho manual.
            

            

              Costumo pegar o serviço desde o começo: entender o problema,
              desenhar a solução, programar e depois ajustar com quem usa. O que
              mais gosto é pegar um processo que hoje é manual e deixar ele
              rodando sozinho.
            

            

              Também trabalho com SoftExpert, principalmente
              nos módulos de Processos,
              Workflow e Formulários, e faço
              fluxogramas para modelar e melhorar processo
              operacional.
            

            

              Fora do trabalho, testo ferramenta nova e estudo arquitetura de
              software. Boa parte do que aprendo vira projeto próprio, como os
              que estão aqui embaixo.

                01 · Desktop
                Destaque
              

              
DBLion

              

                IDE de banco de dados para desktop, em Electron, React e
                TypeScript. A IA sugere o SQL, o plano e o diagnóstico, mas
                quem executa é você. Sete engines passam pelo mesmo contrato
                de adaptadores. Por padrão o app só lê; para escrever precisa
                de um token de uso único, e dá para conferir o que vai sair da
                máquina antes de a IA receber.
              

              

                TypeScript
                Electron
                React
                SQL
                Open source

                02 · IA
                Open source
              

              
Sol-Mode

              

                Skill open source com licença MIT, em português e inglês, com

04 · Criativo

              
MakeYourPoster

              

                Divide uma imagem JPG ou PNG em até 6 folhas A4, com grade de
                corte e margem de cola em milímetros. O recorte de cada página
                se ajusta arrastando. Exporta em PDF A4, JPG ou PNG, tudo
                dentro de um ZIP, e roda no navegador: nada é enviado para
                servidor e não precisa de conta.
              

              

                JavaScript
                HTML
                Tailwind

05 · Ferramenta

              
My Dev Clock

              

                Relógio de terminal para Windows, escrito em Rust. Tem timer,
                cronômetro, contagem regressiva e uma fileira de painéis de
                status com CPU, RAM e Git. São quatro estilos de dígitos, com
                tema e animação de fundo, e a configuração recarrega sem fechar
                o programa. Vem num executável único, sem instalador e sem
                depender de shell.
              

              

                Rust
                TUI
                Windows
                Open source
              

              

                Acessar site
                  
                Baixar o .exe
                  
                Ver no GitHub
